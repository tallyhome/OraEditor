API publique (côté hôte)

Référence courte pour brancher OraEditor dans une application. Le détail TypeScript est aussi dans docs/api.md du dépôt.

Constructeur

const editor = new OraEditor({
  element: "#editor",          // sélecteur ou HTMLElement
  content: "<p>Bonjour</p>", // HTML ou OraDocument
  editable: true,
  toolbar: true,               // ou un HTMLElement hôte
  preset: "full",              // "simple" | "full"
  features: { images, tables, media, ai },
  plugins: [],
  uploadImage: async (file, ctx) => ({ url, alt }),
  openMediaLibrary: async (opts) => items,
  aiProxyUrl: "/ora-editor/ai",
});

Commandes utiles

Texte : insertText, toggleMark, setMark, setBlock, toggleList, setAlign, indent, setLink.

Médias : insertImage, insertVideo, insertAudio, insertEmbed, setNodeAttrs.

Tableaux : insertTable, tableAddRow, tableAddColumn, tableDeleteRow, tableDeleteColumn.

Événements

ready, change, focus, blur, selectionChange, destroy, pluginLoaded, imageUploadStart / Success / Error, aiRequestStart / Success / Error. 

editor.on("change", () => {
  hiddenInput.value = JSON.stringify(editor.getJSON());
});

Plugin minimal

editor.registerPlugin({
  id: "hello",
  name: "Hello",
  version: "1.0.0",
  compatibleCore: "^0.1.0",
  setup(ed) {
    ed.ui.addToolbarButton({
      id: "hello",
      title: "Hello",
      label: "Hi",
      onClick: () => ed.exec("insertText", { text: "Hello" }),
    });
    return () => {};
  },
});

Une dépendance de plugin maximum. Pas de graphe profond.
