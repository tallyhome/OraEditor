Hébergement

cPanel

cPanel sert des fichiers depuis public_html. OraEditor s’installe comme n’importe quel couple JS/CSS. PHP gère l’upload et le proxy IA. L’Update Manager automatique n’est possible que si le compte a Node.js (souvent non, en mutualisé).

Étape 1 — Préparer les assets

Sur votre ordinateur : npm run build puis npm run package. Vous obtenez dist/ora-editor/.

Étape 2 — Envoyer les fichiers

  1. Connectez-vous à cPanel → Gestionnaire de fichiers.
  2. Ouvrez public_html (ou le sous-dossier du site, ex. public_html/app).
  3. Créez un dossier ora-editor.
  4. Uploadez ora-editor.js, ora-editor.css et éventuellement le manifest.
  5. Uploadez aussi, à côté ou dans un dossier PHP, les exemples : upload.php, ai-proxy.php (voir Docs/exemples/).
Ne placez jamais le fichier qui contient la clé API (votre config.php) dans un dossier listable. Idéal : un niveau au-dessus de public_html (ex. /home/user/ora-secrets/config.php) et un require depuis le proxy. Si l’hébergeur l’interdit, protégez le fichier par .htaccess (Deny from all) — ce n’est qu’un pis-aller.

Étape 3 — Page qui charge l’éditeur

Créez public_html/editeur.html (ou une vue PHP) :

<link rel="stylesheet" href="/ora-editor/ora-editor.css">
<div id="editor"></div>
<script src="/ora-editor/ora-editor.js"></script>
<script>
  new OraEditor({
    element: "#editor",
    toolbar: true,
    preset: "full",
    uploadImage: async function (file) {
      const body = new FormData();
      body.append("file", file);
      const res = await fetch("/ora-editor/upload.php", { method: "POST", body });
      return res.json();
    },
    aiProxyUrl: "/ora-editor/ai-proxy.php",
  });
</script>

Adaptez les chemins si le site est dans un sous-répertoire (/blog/ora-editor/…).

Étape 4 — PHP et droits

  • cPanel → Sélecteur PHP : PHP 8.1+ recommandé (8.2+ pour Laravel).
  • Créez public_html/ora-editor/uploads/ et donnez-lui le droit d’écriture (755 ou 775 selon l’hébergeur).
  • Extensions utiles : fileinfo, curl / openssl pour appeler OpenAI.

Étape 5 — HTTPS et CSP

Activez le SSL Let’s Encrypt (cPanel → SSL/TLS Status). L’éditeur et le proxy IA doivent être en HTTPS. Si vous avez une Content-Security-Policy, autorisez 'self' pour scripts/styles et les domaines d’embed (YouTube/Vimeo) si vous utilisez les médias.

Update Manager sous cPanel

SituationQue faire
Mutualisé sans SSH / sans Node Mise à jour manuelle : re-uploader JS/CSS via le Gestionnaire de fichiers. Pas d’Update Manager.
cPanel + Terminal / SSH + Node (Setup Node.js App) Placez exemples/update.mjs hors web, cron quotidien : node /home/user/bin/ora-update.mjs
Vous avez Laravel sur cPanel Job Artisan + cron * * * * * php artisan schedule:run — voir Laravel

Softaculous / Installatron

Ces installeurs ne proposent pas OraEditor. Installez d’abord WordPress, Laravel ou un site PHP vide, puis suivez la page correspondante. OraEditor se greffe sur l’application, il ne la remplace pas.

Webuzo est proche de cPanel (même logique public_html). Voir la page Webuzo pour les écarts (Node.js App, Softaculous).
