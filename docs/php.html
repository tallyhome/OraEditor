Intégration PHP (sans framework)

PHP suffit : une page qui instancie l’éditeur, un script d’upload, un proxy IA. Les fichiers prêts à copier sont dans Docs/exemples/.

Upload

L’éditeur envoie un FormData avec le champ file. Réponse JSON attendue :

{ "url": "https://exemple.fr/ora-editor/uploads/abc.webp", "alt": "nom-original.png" }

Le script d’exemple :

  • refuse tout ce qui n’est pas une image (JPEG, PNG, GIF, WebP) ;
  • renomme le fichier (évite les collisions et les .php.jpg) ;
  • limite la taille (par défaut 8 Mo).
Ajoutez votre propre contrôle d’authentification (session, token). Tel quel, n’importe qui qui connaît l’URL peut uploader.

Sauvegarder le contenu

Au submit du formulaire, stockez de préférence le JSON :

$doc = json_decode($_POST["body_json"], true);
// valider / enregistrer en base
// réaffichage : echo json_encode($doc) dans options.content

getHTML() est un export sanitisé (allowlist). Le JSON reste la source de vérité (tableaux, attrs image, etc.).

Proxy IA

Voir le contrat exact sur la page IA. En PHP :

  1. Copiez config.sample.php → /home/user/ora-secrets/config.php.
  2. Mettez ORA_OPENAI_KEY.
  3. Pointez aiProxyUrl: "/ora-editor/ai-proxy.php".

Sessions et CSRF

Si votre site a déjà une session :

uploadImage: async (file) => {
  const body = new FormData();
  body.append("file", file);
  body.append("csrf", window.CSRF);
  const res = await fetch("/ora-editor/upload.php", { method: "POST", body, credentials: "same-origin" });
  return res.json();
}
