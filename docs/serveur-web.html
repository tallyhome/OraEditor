Hébergement

Apache, Nginx, IIS et autres

OraEditor n’a pas de serveur dédié. Vous servez trois fichiers statiques et, si besoin, deux routes dynamiques (/upload, /ai).

Arborescence recommandée

/var/www/mon-site/
  public/                 ← document root
    index.php
    ora-editor/
      ora-editor.js
      ora-editor.css
      ora-editor.manifest.json
      uploads/            ← images (ou mieux : un disque / S3)
  secrets/
    ora-config.php        ← hors document root
  bin/
    ora-update.mjs

Apache

<VirtualHost *:443>
  ServerName www.exemple.fr
  DocumentRoot /var/www/mon-site/public

  <Directory /var/www/mon-site/public>
    AllowOverride All
    Require all granted
  </Directory>

  # Cache long sur les assets versionnés
  <Location /ora-editor>
    Header set Cache-Control "public, max-age=86400"
  </Location>
</VirtualHost>

Après une mise à jour des JS/CSS, videz le cache ou suffixez ?v=0.1.1 (le manifest porte la version).

Nginx

server {
  listen 443 ssl;
  server_name www.exemple.fr;
  root /var/www/mon-site/public;
  index index.php index.html;

  location /ora-editor/ {
    try_files $uri =404;
    expires 1d;
    add_header Cache-Control "public";
  }

  location /ora-editor/upload.php {
    include fastcgi_params;
    fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
  }

  location ~ \.php$ {
    include fastcgi_params;
    fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
  }
}

IIS (Windows Server)

  1. Créez un site dont la racine pointe vers votre dossier public.
  2. Installez le module URL Rewrite + PHP FastCGI si vous utilisez les proxies PHP.
  3. Ajoutez les types MIME .mjs → text/javascript si vous servez le module ES.
  4. Droits d’écriture NTFS sur le dossier uploads pour le pool d’application.

Plesk / DirectAdmin

Même logique que cPanel : document root du domaine, sous-dossier ora-editor, PHP 8.1+, SSL. Les cron se configurent dans le panneau. Secrets hors httpdocs.

Docker / VPS

# Exemple minimal : Nginx sert les assets, PHP-FPM les routes
volumes:
  - ./public:/usr/share/nginx/html
  - ./secrets:/run/secrets:ro

L’Update Manager tourne dans un conteneur Node ou un job CI qui monte le volume des assets.
