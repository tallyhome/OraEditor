Installer et exploiter OraEditor

OraEditor est un éditeur riche autonome. Le dossier ready/ora-editor/ est déjà prêt : JS, CSS, page, upload et proxy IA. Copiez-le dans votre projet — rien à compiler.

1. Kit prêt

Copier ready/ora-editor/ — pas de npm.

2. Hébergement

cPanel, Webuzo, Apache, Nginx, IIS, Plesk.

3. PHP / Laravel / WP

Intégration concrète, upload et proxy IA.

4. Clés IA

OpenAI, Ollama, mock. Jamais de secret dans le navigateur.

5. Update Manager

Pipeline CHECK → INSTALL → HEALTHCHECK, côté serveur.

Ce que OraEditor n’est pas

  • Ce n’est pas un CMS. Pas de comptes, pas de dashboard admin livré.
  • Ce n’est pas un plugin WordPress officiel (on peut quand même l’embarquer, voir WordPress).
  • L’Update Manager n’est pas un bouton dans l’éditeur. C’est un outil hôte (Node / Artisan / cron).
  • Les clés OpenAI / Anthropic / etc. ne vont jamais dans le JS public.

Prérequis

Pour…Il vous faut
Construire les fichiersNode.js 20+ et npm, une fois, sur une machine de build
Afficher l’éditeurUn serveur web qui sert du HTML + JS + CSS (HTTPS recommandé)
Uploader des imagesUne route hôte (PHP, Laravel, WP-REST…) qui écrit sur le disque
Utiliser l’IA en productionUn proxy serveur + une clé dans un .env hors web
Mettre à jour automatiquementNode (ou un job Artisan) avec droit d’écriture sur le dossier des assets
Le playground développeur se lance avec npm run dev à la racine du dépôt (port 5173). Cette documentation décrit le déploiement dans un vrai projet, pas le playground.

Architecture en une phrase

Le Document Model JSON est la source de vérité. Le DOM n’est qu’une vue. L’hôte stocke ce JSON (ou le HTML sanitisé) dans sa base, et sert les fichiers ora-editor.js + ora-editor.css.
