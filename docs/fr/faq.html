FAQ

Y a-t-il un dashboard / panel admin ?

Non. OraEditor n’est pas un CMS. Pas de stats, pas de licences, pas d’écran de mise à jour intégré.

  • Playground dev : npm run dev (port 5173).
  • Panneau IA : sous l’éditeur, preset Full.
  • Update Manager : à brancher dans votre back-office.

Où est le Update Manager ?

packages/update-manager. Documentation : cette page. Ce n’est pas visible dans le navigateur.

Comment accéder aux différentes IA ?

Preset full + aiProxyUrl pour OpenAI/custom. Mock déjà là. OraAI grisé. Ollama via createOllamaEngine. Détail : clés IA.

La couleur du texte / les colonnes de tableau

Correctifs dans le Core 0.1 : la couleur s’applique au mot ou à la sélection ; une colonne ajoutée recopie l’en-tête (fond de la 1re ligne). Rebuildez et renvoyez les assets si votre serveur a encore un vieux JS.

Les images disparaissent au rechargement

Vous êtes encore en fallback blob:. Branchez uploadImage vers PHP / Laravel / WP-REST.

L’IA répond « réponse invalide »

Le proxy renvoie le JSON OpenAI brut. Reformatez en { patches: [{ path, text }] }.

Peut-on l’utiliser hors ligne ?

Oui pour l’édition (JS + CSS locaux, mock IA). Non pour OpenAI. Ollama possible en local. Uploads : besoin d’un disque ou d’un mode brouillon.

React / Vue / Angular ?

Pas de wrapper officiel. Montez l’éditeur dans un ref / useEffect, détruisez à l’unmount (editor.destroy()). Ne pas ré-instancier à chaque render.

WordPress.org / Composer Packagist ?

Pas encore publiés. Installation par copie de fichiers ou composer path vers packages/laravel.

Licence et sécurité

Le HTML collé est sanitisé (allowlist). Les URLs d’images/embeds sont filtrées (HTTPS, YouTube/Vimeo). Ne faites pas confiance au HTML brut d’un utilisateur pour un echo sans kses / escaping.

Ouvrir cette doc

Double-cliquez Docs/index.html ou servez le dossier Docs/ avec n’importe quel serveur statique. Aucune base de données n’est requise.
