Installation

Le dossier ready/ora-editor/ est déjà compilé et branché (éditeur, upload, proxy IA, page de démo). Vous n’avez rien à construire.

Copiez ready/ora-editor/ vers la racine web de votre projet (public_html/ora-editor/, public/ora-editor/, etc.) puis ouvrez editeur.html.

Intégrer dans votre propre page

Les chemins relatifs marchent si JS/CSS sont dans le même dossier que la page. Sinon :

<link rel="stylesheet" href="/ora-editor/ora-editor.css">
<div id="editor"></div>
<script src="/ora-editor/ora-editor.js"></script>
<script>
  new OraEditor({
    element: "#editor",
    toolbar: true,
    preset: "full",
    locale: document.documentElement.lang || "fr",
    uploadImage: async (file) => {
      const body = new FormData();
      body.append("file", file);
      return (await fetch("/ora-editor/upload.php", { method: "POST", body })).json();
    },
    aiProxyUrl: "/ora-editor/ai-proxy.php",
  });
</script>

Pour les développeurs seulement

Reconstruire le JS/CSS (inutile pour installer) :

npm install
npm run build
npm run package

Cela met à jour ready/ora-editor/ora-editor.js et .css.
