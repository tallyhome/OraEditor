Hébergement

cPanel

Tout est déjà compilé dans ready/ora-editor/. Pas de Node, pas de npm run build : on envoie le dossier et on ouvre la page.

Le kit contient déjà : ora-editor.js, ora-editor.css, editeur.html, upload.php, ai-proxy.php, config.php, dossier uploads/ et .htaccess.

3 étapes

  1. cPanel → Gestionnaire de fichiers → public_html.
  2. Envoyez le dossier ready/ora-editor/ tel quel (glisser-déposer le dossier, ou ZIP puis Extraire).
  3. Ouvrez https://votre-site.fr/ora-editor/editeur.html.

IA (optionnel)

L’éditeur marche sans clé (assistant mock). Pour OpenAI : éditez ora-editor/config.php, remplacez sk-REMPLACER. Ce fichier n’est pas lisible depuis le navigateur (.htaccess).

Si les images ne s’enregistrent pas

Clic droit sur ora-editor/uploads → Permissions → 755 ou 775. PHP 8.1+ dans le sélecteur cPanel.

Mettre à jour plus tard

Sur un mutualisé : renvoyez simplement les nouveaux ora-editor.js et .css du dossier ready/ (après une nouvelle version du projet). Pas besoin de Node sur le serveur.

Webuzo, FTP, Plesk : même geste — copier ready/ora-editor/ dans la racine web. Voir Webuzo et Apache / Nginx.
