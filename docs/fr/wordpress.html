Frameworks

WordPress

Oui, on peut l’installer sur WordPress. Il n’existe pas encore de plugin officiel sur wordpress.org. On embarque le Core comme assets d’un petit plugin : shortcode, réglages (clé IA), routes REST pour l’upload et le proxy.

OraEditor ne remplace pas Gutenberg « en un clic ». Deux usages réalistes : formulaire / page front (shortcode), ou metabox sur un type de contenu (vous stockez le JSON dans un post meta). Remplacer entièrement l’éditeur de blocs est un projet à part.

Installation manuelle

  1. Créez wp-content/plugins/ora-editor/.
  2. Copiez-y exemples/wordpress-plugin/ora-editor.php.
  3. Créez wp-content/plugins/ora-editor/assets/ et copiez ora-editor.js + ora-editor.css depuis ready/ora-editor/ (déjà compilés, pas de npm).
  4. Extensions → Plugins installés → activez OraEditor.
  5. Réglages → OraEditor : collez la clé OpenAI (stockée en option WordPress, jamais imprimée dans le HTML public).

Shortcode (front ou page)

[ora_editor id="mon-editeur" preset="full"]

Dans un thème ou un formulaire de contact maison, le shortcode injecte le <div>, enqueue les assets, et initialise new OraEditor avec :

  • uploadImage → POST /wp-json/ora-editor/v1/upload (nonce + upload_files)
  • aiProxyUrl → /wp-json/ora-editor/v1/ai

Metabox (édition d’un article)

Le plugin d’exemple ajoute une metabox « Contenu OraEditor » qui :

  1. charge le JSON depuis _ora_document ;
  2. au save_post, lit $_POST["ora_document"] (JSON) ;
  3. peut aussi stocker un HTML sanitisé dans _ora_html pour le front.
// front-page / single
$html = get_post_meta(get_the_ID(), "_ora_html", true);
echo wp_kses_post($html);
Le HTML d’OraEditor est déjà sanitisé côté Core (allowlist). wp_kses_post reste une seconde barrière ; il peut retirer des attrs (tableaux, embeds). Pour un rendu fidèle, préférez un renderer PHP du JSON, ou un kses étendu.

cPanel / Webuzo

Installez WordPress via Softaculous, puis uploadez le dossier plugin (ZIP ou File Manager). Même règles : HTTPS, PHP 8.1+, dossier uploads WP déjà inscriptible.

Ce qui n’est pas fourni

  • Bloc Gutenberg officiel (on peut envelopper le shortcode dans un bloc HTML personnalisé).
  • Remplacement de TinyMCE / Classic Editor pour tous les posts.
  • Mises à jour via le dépôt wordpress.org — utilisez l’Update Manager sur le dossier assets/ du plugin, ou un FTP manuel.
