Démarrer

Installation générale

Quelle que soit la stack (cPanel, Laravel, WordPress, Nginx…), le rituel est le même : construire ou récupérer les assets, les placer dans un dossier public, initialiser l’éditeur.

1. Produire les fichiers

Sur une machine qui a Node.js 20+ (votre PC, un CI, pas forcément le serveur de prod) :

cd chemin/vers/OraEditor
npm install
npm run build
npm run package

Résultat dans dist/ora-editor/ :

FichierRôle
ora-editor.jsBundle IIFE. Expose globalThis.OraEditor (script tag)
ora-editor.mjsModule ES, pour bundlers (Vite, Webpack)
ora-editor.cssStyles toolbar, contenu, tableaux, panneau IA
ora-editor.manifest.jsonVersion, canal, checksums — lu par l’Update Manager
Sans npm run package, les mêmes JS/CSS sont déjà dans packages/core/dist/ après npm run build.

2. Copier vers le projet hôte

Placez au minimum le JS et le CSS dans un dossier servi en HTTPS :

Type de projetEmplacement typique
HTML / PHP / cPanelpublic_html/ora-editor/
Laravelpublic/vendor/ora-editor/ (ou php artisan vendor:publish --tag=ora-assets)
WordPresswp-content/plugins/ora-editor/assets/
App JS (npm)dépendance @ora-editor/core + import CSS

3. Premier éditeur (HTML)

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="/ora-editor/ora-editor.css">
</head>
<body>
  <div id="editor"></div>
  <textarea name="body" id="body" hidden></textarea>

  <script src="/ora-editor/ora-editor.js"></script>
  <script>
    const editor = new OraEditor({
      element: "#editor",
      toolbar: true,
      preset: "full", // ou "simple" : texte + images, sans tableaux / médias / IA
    });

    // Persistance : JSON (recommandé) ou HTML sanitisé
    document.querySelector("form")?.addEventListener("submit", function () {
      document.getElementById("body").value = JSON.stringify(editor.getJSON());
      // alternative : editor.getHTML()
    });
  </script>
</body>
</html>

4. Presets

PresetInclus
simpleTexte, titres, listes, liens, images
full (défaut)Simple + tableaux, vidéo/audio/embed, panneau IA

On peut affiner avec features: { tables: false, ai: true }.

5. Import npm (app moderne)

import OraEditor from "@ora-editor/core";
import "@ora-editor/core/style.css";

const editor = new OraEditor({
  element: "#editor",
  toolbar: true,
  preset: "full",
});

Presets dédiés : createSimpleEditor (@ora-editor/simple) et createFullEditor (@ora-editor/full).

6. Adapters que l’hôte doit fournir

OptionQuandContrat
uploadImage Bouton image, drag & drop, collage (file, ctx) => Promise<{ url, alt? }> — URL publique, pas de Base64
openMediaLibrary Bouton médiathèque Ouvre votre UI, renvoie des items { url, alt }
aiProxyUrl Preset full + IA distante URL POST de votre backend (voir clés IA)
Sans uploadImage, le Core utilise un fallback blob: (aperçu local seulement). Les images disparaissent au rechargement. En production, branchez toujours un upload hôte.
